# 5D Muscle Log — GitHub Pages

## Įkelk taip

1. Prisijunk prie GitHub.
2. Spausk **New repository**.
3. Pavadinimas: `5D-Muscle-Log`.
4. Pasirink **Public**.
5. Spausk **Create repository**.
6. Pasirink **Add file → Upload files**.
7. Įkelk VISUS šio paketo failus.
8. Spausk **Commit changes**.
9. Eik į **Settings → Pages**.
10. Prie **Source** pasirink **Deploy from a branch**.
11. Branch: **main**.
12. Folder: **/(root)**.
13. Spausk **Save**.

Tavo adresas bus maždaug:

`https://TAVO-GITHUB-VARDAS.github.io/5D-Muscle-Log/`

### Android
Atidaryk adresą Chrome → **⋮** → **Install app** arba **Add to Home screen**.

### iPhone
Atidaryk adresą Safari → **Share** → **Add to Home Screen**.

Treniruočių duomenys saugomi tame telefone / naršyklėje. Periodiškai naudok **Eksportuoti** atsarginei kopijai.
